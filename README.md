# Intelligent Plant Recognition & Learning System - Final Year Project

A full-stack application for monitoring plant species and healthy.
**Three Core Function**
- Plant Recognition System
    - Upload plant images
    - AI-powered species identification
    - Confidence score display (accuracy percentage)
    - Scan history with filter (plant/disease)
    - View detailed plant information after recognition
- Disease Detection System
    - Separate ML model for plant disease identification
    - Upload disease images
    - View detailed disease information after recognition  
- Interactive Learning System
    - Auto-generated quizzes (plant/disease/mixed)
    - Custom admin-created quizzes
    - Multiple choice format with images

## 🛠️ Technologies Used

### Backend
- **C#** - API development
- **Python** - ML model training and inference
- **Flask** - Python backend API for ML predictions
- **OpenCV** - Image preprocessing
- **TensorFlow** - Convolutional Neural Network (CNN) model training for image classification
- **MySQL** - Database

### Frontend
- **React.js** - Framework
  
### Frontend Setup
- cd frontend
- npm start

### Backend Setup
- cd backend
- venv\Scripts\activate
- python smart-api-v2.py
