# Intelligent Plant Recognition & Learning System - Final Year Project

A full-stack application for plant monitoring and management.

## 🛠️ Technologies Used

### Backend
- **C#** - API development
- **Python** - AI/ML processing
- **Flask** - Web framework

### Frontend
- **React** - Frontend build
  
### Prerequisites
- Python 3.8+
- Node.js 14+
- .NET Core 6.0+

### Frontend Setup
- cd frontend
- npm install
- npm start

### Backend Setup
- cd backend
- python -m venv venv
venv\Scripts\activate  # Windows
# or
source venv/bin/activate  # Mac/Linux

pip install -r requirements.txt
python app.py
